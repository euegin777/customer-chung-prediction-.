# Customer Churn Prediction Using Artificial Neural Network (ANN)

## 📌 Project Overview

This project focuses on predicting customer churn using an **Artificial Neural Network (ANN)** built with TensorFlow and Keras.

Customer churn prediction helps businesses identify customers who are likely to stop using their services. By analyzing customer information such as tenure, monthly bills, and contract type, the model predicts whether a customer will stay or leave.

The project demonstrates data preprocessing, feature encoding, feature scaling, neural network development, model training, and prediction.

## 🎯 Objectives

- Predict whether a customer will leave or stay.
- Build an Artificial Neural Network using TensorFlow and Keras.
- Perform data preprocessing and feature engineering.
- Train and evaluate a deep learning classification model.
- Visualize training accuracy, validation accuracy, and loss.

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- TensorFlow
- Keras
- Scikit-learn
- Jupyter Notebook

## 📊 Dataset Description

This project uses a randomly generated practice dataset containing 1,000 customer records.

The dataset includes the following features:

| Feature | Description |
|---|---|
| Tenure | Number of months a customer has stayed |
| Monthly Bill | Customer's monthly payment |
| Contract | Monthly or Yearly contract |
| Churn | 0 = Stay, 1 = Leave |
